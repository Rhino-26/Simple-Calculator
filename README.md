🧮 Advanced Responsive Calculator Web App

A fully functional, modern, and responsive Calculator Web Application built using HTML, CSS, and JavaScript. This project combines both standard and scientific calculator features within a sleek, user-friendly interface designed to match a precise UI layout.

The application delivers real-time calculations, advanced mathematical operations, dynamic themes, and a smooth user experience across all devices.

🚀 Features
🧮 Core Calculator
- Basic arithmetic operations: +, −, ×, ÷
- Real-time input and result display
- Clear (C) and delete (⌫) functionality
- Decimal number support
- Input validation to prevent invalid expressions
  
🔬 Scientific Mode
- Advanced mathematical functions:
- Trigonometric: sin, cos, tan
- Logarithmic: log, ln
- Square root (√)
- Power (^)
- Parentheses support
- Toggle between Standard and Scientific modes
  
📜 History Panel
- Stores previous calculations with results
- Hidden by default for a clean UI
- Toggle visibility using a History button
- Option to clear history
  
⚙️ Settings Panel
- Easily accessible via settings icon
  
Includes:
- Theme selection
- Mode switching
- About section
  
🎨 Theme System
- Multiple built-in themes:
- Light Mode
- Dark Mode
- Neon Mode
- Glassmorphism Mode
- Dynamic theme switching without page reload
  
ℹ️ About Section

Displays:
- App name
- Version
- Developer info
- Short description
  
📱 Responsive Design
Fully optimized for all screen sizes:

- Mobile (≤ 600px): Compact, touch-friendly layout
- Tablet (601px – 1024px): Balanced UI with partial scientific features
- Laptop (1025px – 1440px): Full layout with proper spacing
- Desktop (1441px+): Wide layout with optional side panels

Built using CSS Grid, Flexbox, and Media Queries for seamless responsiveness.
